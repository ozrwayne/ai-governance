# 中枢设备存储法 说明书

## 要解决的问题

知识库、代码、数据、素材四处共用一套编号，规则散在知识库 `00.01 规矩/存储规矩.md`、知识库根目录 `AGENTS.md`、`00.19 强制规则` 中，彼此有出入，且均未登记，依 C2026-001 v1 A8 不是法。发新类、新条没有成文标准，号码索引中曾出现同号两用，号码索引本身有两份。

## 适用范围

本法适用于任何设备上的代理对中枢设备存储库所作的动作，包括库的增设与撤销、编号、导航、文件、标签、资料去向与迁移。私密范围的读取由《代理动作程序法》规定，本法只规定私密资料的存放位置。

## 所依据的上位法与相关法

上位法：C2026-001 v1 A6、B4、E3、E4。相关法：S2026-002 v1 §6。法源关系在说明书中说明，不在本法正文直接引用其他法律。

## 所修改或废止的条文

无。原存储规矩、`AGENTS.md`、强制规则未经登记，不是法，无须废止。

## 条文来源与本次决定

- 编号、单一现行文件、来源标签、原文保全与迁移确认，承接原存储规矩、知识库入口文件及本次会话中的决定。
- §17 至 §19：新类须有两件以上互不从属的事务；新条须持续加入文件且须单独查找；编号只分配给资料、作品与事务。
- §6、§15、§21：各库的资料类型、各区的类型及具体条目设置载于号码索引，不把「产品库」「客户需求库」等可变目录配置写进法律。类型模板不强制覆盖现有各类；已有号码及其用途保留。
- §22、§37、§40、§42 至 §44、§47：账号、待分拣、人类主权者材料、原始存档、收藏、归档等用途由号码索引定位，法规定其处理规则。
- §2、§46：公报只承担中枢设备与存储根目录的指定；日常设库、设区及目录配置依法更新号码索引，不为每项另发公报。
- §26 至 §30：号码索引用于登记与定位，类导航用于说明收存范围与组织方式；每类保留一份 `导航.md`，其中的编号与名称由号码索引生成，不另建重复索引。新类建立导航，新条同步登记与补充导航；导航中的组织方式不得违反本法。
- §36、§37：全部 Markdown 文件载明来源与日期；自媒体区另载明账号、平台、选题、阶段、状态。
- 迁移通则前置为 §3，更换中枢设备的规定移至 §46；本法内部引用只引用此前已出现的条文。
- 本文本经人类主权者同意提交登记；生效以完成法定登记程序为准。
