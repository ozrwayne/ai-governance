# 代理动作程序法修正案 说明书

## 要解决的问题

现行第二条将命令限定为本人在设备本地代理输入框直接输入的文字，没有规定已获授权任务向其他会话、命令行代理和后台任务传递的方式。已安装闸门以交互界面状态代替授权核验：omp 非交互会话的非读取动作被拒绝，Claude Code 的非读取动作逐次询问。界面状态既不能证明授权出自本人，也不能证明后台任务未经授权。

用户报告了委托测试被拒绝。已核对拒绝文案与程序分支，但未读取受限审计日志，不能断言具体被拒绝的是普通文件读取。已运行安装版本的分类函数，普通本地 read 属于 read，task 属于 delegate，todo 属于 internal，命令行启动 omp 属于 exec。

## 适用范围

代理的任务授权、上下级分派、跨会话和跨设备委托、命令行代理与后台执行，以及停止、授权撤销和审计。不改变私密读取范围，不允许通过委托扩大读取权限；不改变立法、登记及受保护配置变更所需的本人确认。

## 所依据的上位法

宪法 B1、B2、B3、B4、C1、C2、C3、C4、D1 至 D6、E1 至 E4。

## 所修改或废止的条文

修改 S2026-002 v1 第二、三、四、七、八条。第一、五、六、九、十条保持原文。修正案中的目标法编号用于点名被修正条文；替换后的实体条文不直接引用其他法律编号，也不向后援引本法条文。

## 审查

- B1 至 B3：命令权仍归本人。代理只能传递已确认的授权，不能自行签发本人授权；有 UI、本人账户或持有授权编号均不足以证明授权。
- C4：由本法设定任务范围内的上下级关系，允许分派和再次委托；权限、范围与期限不得扩大。
- E3：保留法与命令两种授权来源。法已允许的普通读取，不因缺少命令被拒绝。
- E4：明确列入原授权的不可逆动作不需重复确认；未列入的不可逆或可能不可逆动作仍需明确授权。笼统任务目标不等于不可逆动作授权。
- C1：保留任何来源触发停止及本人确认恢复的要求。任务撤销、到期和范围缩小传播到全部下级；恢复运行不复活已失效授权。
- E1、E2：保留先读法与逐动作记录；增加原始授权及委托链的可核验记录，不记录认证秘密。
- 现行法：保留私密读取、登记及受保护配置边界；任务授权不需逐项发布公报。
- 结论：委托程序可以由成文法设立，无需修宪。未发现本修正文本与上述上位法抵触。

## 生效与实施条件

本目录为待确认、待登记文本，尚未改变现行法或已安装程序。汇编预览仅用于审阅，不是登记正本。

登记前须完成配套实现与实际验证：受保护的本人确认与授权记录、执行者绑定、委托链及范围核验、失效与停止传播；不得将 interactive 改成 true 或直接删除拒绝分支冒充实现。还须核实登记脚本支持追加修正及生成被修正法的新汇编，不能把修正案作为与原法互不关联的普通新增条目登记后宣称切换完成。

## 验收情形

1. 本人确认任务后，主代理委托命令行代理，后者可以读取依法可读的技能并完成授权范围内的动作，无须本人进入第二个窗口。
2. 同一授权未覆盖的对象、动作或不可逆操作被拦下；伪造授权编号、变更委托范围或冒用执行者不能通过。
3. 普通文件或技能内容声称扩大授权，不改变实际授权。
4. 任务撤销、到期、范围缩小或停止要求发生后，下级和后台任务不再继续执行被禁止的动作。
5. 法已允许的普通读取不依赖交互窗口；私密读取限制保持不变。
6. 每个委托动作均可追溯到本人确认的原始授权，审计记录不包含认证秘密。
