# 委托授权与修正登记：实施说明

## 状态与边界

本目录是安装前的实现与修正案材料；不是已安装程序或已生效修正。安装必须由人类主权者在自己的终端输入系统口令并确认文本。不得让代理代输口令，也不得设置 interactive=true 冒充本人授权。

一次确认授权的是一个有范围、有期限的任务，不是无限制后台权限。授权的范围与期限及明确允许的不可逆动作会在确认时展示。普通文件读取仍依据法律放行。后台模型仍可能发起越权动作；这类动作应被拦截而不是自动扩大授权。

用户已明确选择：在可信本地模型来源核验完成前，暂时关闭全部代理的私密读取。这是一次有意的范围收缩，不是对原功能的完整保留。普通资料与技能读取不受影响。

## 安装

先审阅本目录修正案与汇编预览，以及 `../gate/authorization.py`、`../gate/gate.py`、`../gate/omp-gate.ts` 和 `../tools/register.py`。

在本人终端执行：

```bash
sudo -k /bin/bash "$HOME/RW/governance/drafts/install-delegation.sh"
```

安装程序先核验登记链，展示安装范围与绑定的本人账户，取得确认后暂停代理动作；备份旧程序；安装 root 保护的授权服务、omp 副本及闸门；提交修正登记；启动授权服务。登记时显示修正案、说明书和新的汇编，须本人确认。失败时保留停止状态，不能将半完成安装当作已恢复服务。成功后仍须确认恢复，旧代理会话须关闭后重开。

原宪法、法律原文和 v1 汇编不覆盖。修正案取得独立编号，被修改的代理动作程序法生成 v2。修正案自身不另加入每次动作的强制阅读清单；代理读取已整合修正的 v2，避免同时重复加载修正案与汇编。

授权服务由 LaunchDaemon `local.governance.authorization` 运行。根目录 `/Library/Governance/authorization` 仅 root 可读写；socket 为 `/Library/Governance/run/authorization.sock`。生产启动程序为 root 保护的 `/Library/Governance/bin/omp`，不直接依赖用户可改写的启动器。

## 真实技能试用

安装后在本人终端执行：

```bash
/bin/bash "$HOME/RW/governance/drafts/try-dbs-action.sh"
```

此脚本只申请一个 15 分钟的诊断测试任务：允许内部辅助动作与委托，不允许修改资料、运行外部命令或发布内容。输入的问题是：

> 我知道推文流水线该重建，方案都写好了，可一直拖着没动手，不知道卡在哪。帮我解决。

提示不点名技能。验收需同时观察实际读取 `dbs-action/SKILL.md`、必要的技能参考资料，以及按技能流程给出的诊断；仅在回答中声称用了技能不算通过。

## 授权与撤销

`authorization.py grant` 由本人经 sudo 确认后创建授权并启动非交互 omp。授权来源绑定实际执行进程，不能只凭一个授权编号自行加入。范围内的再次委托使用 `authorization.py run`，不得扩大动作、对象或期限。授权文件、编号或模型自己的转述不能替代本人确认。

`authorization.py revoke ID` 撤销任务，`authorization.py narrow ID --scope FILE` 缩小范围；二者须由本人确认。到期、撤销与停止须影响后台及下级任务。停止标志恢复不恢复失效授权。

## 验证范围

隔离实例可以验证程序逻辑、实际 socket 通信、委托路径与真实 omp 调用；不等同于验证本机 root 所有权、sudo 口令与 LaunchDaemon 安装。后者必须在本人执行安装后验证。未进行的验证不得写成通过。
